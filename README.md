# 寻路小队 · A* 互动实验室（第三版优化）

一个使用原生 HTML、CSS 和 JavaScript 实现的寻路教学项目。通过 A* 简介、15 格迷你例题、可编辑地图和 A* / Dijkstra 同图竞速，理解算法如何比较候选、记录来路并找到最短路径。

## 快速开始

下载或克隆仓库后，用现代浏览器打开 [`dist/index.html`](dist/index.html)。请保留完整的 `dist` 目录，脚本、样式和图片均从本地加载。

浏览页面无需安装依赖、启动后端或执行构建，也不需要 Node.js 或 Python。Node.js 仅用于运行仓库中的校验脚本。

## 学习顺序与功能

建议按 **A* 简介 → 15 格迷你例题 → 互动实验室 → 博士竞速** 的顺序学习。

| 环节 | 学习与操作内容 |
| --- | --- |
| A* 简介 | 理解已走步数 `g`、预估剩余步数 `h`，以及候选评分 `f = g + h`。 |
| 15 格迷你例题 | 在 3 × 5 地图上比较候选的 `g / h / f`，选择下一格、查看本轮答案、返回上一轮或从头再试；最终最短路线为 8 步。 |
| 互动实验室 | 编辑 12 × 9 地图，逐步观察搜索、代码高亮和路线回溯，查看格子分数并预测下一格。 |
| 博士竞速 | 在同一地图上比较 A* 与 Dijkstra 的搜索格数、路径步数和到达回合。 |

### 互动实验室

1. 选择「绕过围墙」「曲折走廊」「空白」「无路可走」场景，或使用障碍、橡皮、起点、终点工具编辑地图。鼠标支持点击和拖动，触屏可逐格点击；起点与终点不能重合。
2. 点击「下一步」逐行观察，或点击「开始演示」自动播放。支持暂停、上一步、速度调整和进度拖动。
3. 演示期间点击格子查看 `g / h / f`；出现待探索格后，可点击「猜猜下一格」并选择蓝色候选格。
4. 要重新编辑地图，点击重置按钮。地图、代码高亮、说明文字和统计会随回放同步更新。

页面展示的是 18 行 Python 教学核心流程，定义在 `dist/app.js` 的 `TEACHING_CODE` 中；实际运行的是 `dist/astar.js` 内的 JavaScript 算法。本分支的 Python 展示依赖 `init`、`priority`、`neighbors`、`trace` 等辅助函数说明，未附可独立执行的 `.py` 文件。

## 博士同图竞速

从页首点击「博士竞速」。蓝队 A* 与橙队 Dijkstra 共用一个赛场、起点与终点，可以选择场景、点击编辑，或点击「使用实验室当前地图」导入上方地图。支持开始 / 暂停、上一回合、下一回合、速度调整、进度回放和重置。

每回合两队各选出一个搜索节点（含选出的终点）；各自找到最短路线后，每回合沿路线走一格。到达回合 = 搜索回合 + 路径步数，只是公平的教学计时，不代表真实运行耗时。搜索时博士留在起点，边框指示当前搜索节点。两队均求最短路，A* 不保证在每张地图上领先。

## 算法约定

- 地图只允许上下左右移动，每步代价为 1，邻居遍历顺序为上、右、下、左。
- A* 使用曼哈顿距离估计剩余步数，先比较 `f`，同分时比较 `h`，完全相同时保留先加入的候选格。
- Dijkstra 按 `g`、加入顺序选择候选，相当于令 `h = 0`。
- JavaScript 的候选集合使用保留插入顺序的 `Set`，通过线性遍历选择下一格，便于阅读和教学。
- 内部格子编号从 0 开始，从左到右、从上到下递增；页面坐标采用 `(列, 行)`，从 1 开始。例如宽度为 5 时，编号 `5` 对应页面坐标 `(1, 2)`。

## 源码阅读顺序

| 文件 | 职责 |
| --- | --- |
| [`dist/astar.js`](dist/astar.js) | A* 算法与教学快照。从 `buildEvents` 开始阅读；`recordStep` 记录每一步，辅助函数负责距离、选点、邻居和回溯。 |
| [`dist/walkthrough.js`](dist/walkthrough.js) | 调用同一份算法，将搜索记录按轮组织为 15 格例题，绑定候选答题、答案说明和前后翻页。 |
| [`dist/app.js`](dist/app.js) | 实验室的地图编辑、播放、代码高亮、分数查看和预测问答。 |
| [`dist/race-engine.js`](dist/race-engine.js) | 独立于页面的双算法搜索快照、行走过程与竞速计时。 |
| [`dist/race.js`](dist/race.js) | 竞速地图、博士动画、控制与结果展示。 |
| [`dist/index.html`](dist/index.html) | 页面结构与脚本入口。 |
| [`dist/style.css`](dist/style.css)、[`dist/walkthrough.css`](dist/walkthrough.css)、[`dist/race.css`](dist/race.css) | 主页面、迷你例题和竞速样式。 |
| [`dist/assets/`](dist/assets/) | 页面插画与 AI 生成的透明底博士跑步素材；原始生成提示见 `doctor-run.prompt.txt`。 |

教学代码与算法事件通过 `recordStep` 的行号对应。修改 `TEACHING_CODE` 或搜索流程时，应同步检查行号映射及迷你例题的分轮逻辑；竞速 A* 的搜索顺序也需要与教学算法保持一致。

## 校验算法

校验脚本仅使用 Node.js 内置模块，无需 `npm install`。使用支持 `node:assert/strict` 和 `Array.prototype.at` 的 Node.js 版本，在仓库根目录运行：

```bash
node check.cjs
node check-race.cjs
```

| 脚本 | 检查内容 |
| --- | --- |
| `check.cjs` | 将 A* 与独立的广度优先搜索（BFS）在 100 张随机地图上比较，校验最短步数、路线合法性、无路提示和候选优先级。 |
| `check-race.cjs` | 在 100 张随机地图及平局、无路、单列、起终点相同等场景下，校验两队最短路径、教学 A* 搜索次序一致性、行走回合及快照独立性。 |

这些脚本验证算法和竞速数据；修改页面交互或样式后，还应在浏览器中检查例题答题、地图编辑、回放及竞速显示。
